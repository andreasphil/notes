- Evan You, author of Vue and Vite, shares his thoughts on the future of [Developer Tooling in the Agentic Era](https://www.youtube.com/watch?v=FpC35eggY6Y) at ViteConf 2026. His core point is that _"tool design has a second audience"_---agents, which need predictability, structure, and fast feedback loops. Unsurprisingly, he thinks the Vite ecosystem is ideally positioned for this new era. I agree! And I'd add that all of these qualities improve the developer experience for humans, too.

- With 2027 around the corner, [people](https://www.sarasoueidan.com/blog/interop-2027-rankings/) [are](https://pawelgrzybek.com/my-interop-2027-picks/) [sharing](https://www.joshwcomeau.com/css/interop-2027/) their wishlists for what browser vendors should focus on during [Interop](https://wpt.fyi/interop-2026) 2027. A good telescope for features on the web platform's horizon that many people are excited about, but that aren't widely supported yet.

- [Plan mode is dead,](https://www.aymannadeem.com/artificial/intelligence,/developer/tools/2026/09/24/plan-mode-is-dead.html) and one of the people behind Claude Code [agrees on Hacker News:](https://news.ycombinator.com/item?id=49850929) _"I realized that I wasn't using plan mode anymore because the model just got it, and because for the increasingly complex work I asked the model to do, planning had become interactive and iterative."_

- New to the Baseline: [`alpha()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/alpha) is a more ergonomic way of adding transparency to a color. [`progress()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/progress) tells you how far a value has progressed between a start and an end value, as a number between 0 and 1. Multiply that by a unit and you get font sizes or spacings that scale with the viewport. Kevin Powell has an explainer on [YouTube.](https://www.youtube.com/watch?v=bLB90QwRki4)

- After years of working with JavaScript frontend frameworks, I went back to classic server-rendered HTML for some projects, and one of the first things that tripped me up was keeping the scroll position when navigating back and forth between pages: [The root scroller and how not to lose it.](https://polypane.app/blog/the-root-scroller-and-how-not-to-lose-it/)

- [Deno is joining Cloudflare,](https://deno.com/blog/cloudflare) and by Deno they mean Deno _the company_: Cloudflare is interested in [celld,](https://celld.dev) Deno's open-source, self-hosted implementation of Cloudflare's [Durable Objects.](https://www.cloudflare.com/products/durable-objects/) Deno _the runtime_ will receive another year of security updates, after which it will be handed over to the community---which might well mean it will effectively be sunset.

- Two recent additions to my toolbox: [zoxide,](https://github.com/ajeetdsouza/zoxide) which offers smart bookmarks and quick directory switching based on your usage patterns, and [superfile,](https://superfile.dev) a pretty and efficient terminal-based file manager.

- [`Element.getAnimations()`,](https://developer.mozilla.org/en-US/docs/Web/API/Element/getAnimations) a convenient API for inspecting an element's animations, each with a `finished` promise. Useful, for example, to react programmatically once an element has finished fading out.

- Ever double-tapped a button on mobile, only to have the page zoom in? [There's a CSS property for that.](https://piccalil.li/blog/stop-buttons-triggering-zoom-when-theyre-double-tapped/)

- [Butterick's Practical Typography,](https://practicaltypography.com) a gold mine of advice that helps typography beginners like me make text look pretty and readable.

### Notable releases:

- [**Claude Code 2.1.287,**](https://code.claude.com/docs/en/changelog#2-1-287) adding [mods](https://claude.dev/mods/)---little plugins that can extend the UI and hook into tool calls and other events.

- [**Claude Opus 5.5,**](https://www.anthropic.com/claude-opus-5-5) [**Sonnet 5.5,**](https://www.anthropic.com/claude-sonnet-5-5) and [**Haiku 5.5,**](https://www.anthropic.com/claude-haiku-5-5) refreshing Anthropic's entire lineup with better quality and performance at a lower cost per task across the board. Also check out their guides for [getting the most out of Opus 5.5](https://claude.dev/blog/getting-the-most-out-of-opus-5-5/) and [building with Sonnet 5.5.](https://claude.dev/blog/building-with-claude-sonnet-5-5/)

- [**GPT-6.1 Sol,**](https://openai.com/index/introducing-gpt-6-1-sol/) [**GPT-6.1 Terra,**](https://openai.com/index/introducing-gpt-6-1-terra/) and [**GPT-6 Luna,**](https://openai.com/index/introducing-gpt-6-sol-and-luna/) OpenAI's counterparts to the Claude models, with similar improvements. I've lost track at this point; just use the latest version of your favorite model, and stuff will be better I guess?

- [**Java 27,**](https://www.baeldung.com/java-27-new-features) turning on compact object headers by default, making G1 the default garbage collector on all machines, and other mostly targeted changes. Seems like a sign of a mature language.

- [**Node 26.10,**](https://nodejs.org/en/blog/release/v26.10.0) adding built-in `debounce` and `throttle`, and [**26.12,**](https://nodejs.org/en/blog/release/v26.12.0) stabilizing the [config file.](https://beta.docs.nodejs.org/cli#--config-filepath---config-file)

- [**Nuxt 4.6,**](https://nuxt.com/blog/v4-6) shipping a new CLI with an interactive dev panel, cookie-based sessions via `useSession`, and opt-in Vue Vapor mode for individual components and pages.

- [**OpenCode 2,**](https://anoma.ly/notes/opencode-2-0/) a _"major overhaul"_ rebuilding its internal architecture, redesigning its plugin API, supporting [Code Mode](https://blog.cloudflare.com/code-mode/) for MCP servers, and adding background tasks.

- [**SvelteKit 3,**](https://svelte.dev/blog/sveltekit-3-is-here) polishing what was in the [release candidate](@/notes/2026-08.md#notable-releases) back in August.

- [**Vite+ 1.0,**](https://voidzero.dev/posts/announcing-vite-plus-1-0) going stable as a unified toolchain behind a single `vp` command that manages the runtime, package manager, dev server, linting, formatting, testing, and builds. Watch the [demo at ViteConf.](https://youtu.be/PfyIEgLzNYI?t=3398)
